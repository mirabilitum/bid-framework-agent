# 构建任务

## 1. 骨架构建：格式模板章节优先

**核心原则**：招标文件通常有两处定义响应文件结构：
- **skeleton（投标文件组成）**：概述性列表，告诉你响应文件有哪些部分
- **format_templates（投标文件格式）**：完整的格式定义，包含每一项的正确标题、编号

**当format_templates存在时，以format_templates为准构建框架**：

### 1.1 章节标题以格式模板为准

skeleton可能写：
```
（1）资格及资信证明部分  ①响应函  ②供应商的资格及资信证明文件
```

但格式模板章节实际是：
```
封面格式(资格及资信证明部分)    ← 章节名
索引：一、响应函  二、供应商的资格及资信证明文件    ← 索引编号
一、响应函（正文）                                  ← 实际标题
二、供应商的资格及资信证明文件（正文）
```

框架应使用：
- 章节标题 → "资格及资信证明部分"（从封面/索引提取，不带skeleton的编号）
- 子项标题 → "一、响应函"、"二、供应商的资格及资信证明文件"（格式模板的实际编号）

### 1.2 格式模板的每一项都必须出现

格式模板章节中的所有内容层级必须完整反映到框架中，不能只看skeleton的概括。不能遗漏、不能概括为一句话。

### 1.3 扁平skeleton（无格式模板章节时）

如果没有format_templates，则直接使用skeleton作为骨架：
- 每项 → level 1 节点，保留原文编号和标题
- 不要自行分组

### 1.4 无明确skeleton时的通用格式兜底

当skeleton为空或source为"inferred"时，按以下优先级：

**优先级1**：从"符合性审查"/"采购需求"/"服务需求"等章节提取的多级目录结构，与评分因素综合对比后作为骨架

**优先级2**：通用响应文件框架：
```
一、资格性文件
二、商务部分
三、技术部分/服务部分
四、价格部分
五、其他资料
```

### 1.5 禁止事项

- **不得**自创标题或编号（只能来自招标文件原文或通用格式框架）
- **不得**遗漏格式模板中的任何项目
- **不得**将多个子项概括为一句话

## 2. 章节封面和索引

检查format_templates中是否有封面格式：
- 有"封面格式(xxx)"等 → has_chapter_covers=true
- 为每个对应的一级章节生成cover_page和index_page
- 没有封面格式 → has_chapter_covers=false

## 3. 格式模板子项的标题处理

- 格式模板编号（如"格式 7-1"、"格式 8-1"）在标题中**只保留序号**，去掉"格式"二字
- 示例：`格式 7-1 供应商资格信用承诺函` → `7-1 供应商资格信用承诺函`

## 4. 标题格式

- 格式模板中的标题通常是居中的，必须加 `[CENTER]` 前缀
- 只有明确左对齐的标题才不加前缀

# 输出格式

**单包或scoring_shared=false时**：
```json
{
  "has_chapter_covers": true,
  "framework": [ ... ]
}
```

**scoring_shared=true（多包共用评分标准）时**，在顶层加 `applicable_packages`，值为packages数组中所有包的id列表：
```json
{
  "applicable_packages": ["1", "2", "3"],
  "has_chapter_covers": true,
  "framework": [ ... ]
}
```

# 注意事项

1. **只输出骨架**：所有节点的content留空（空字符串""），后续步骤填充
2. 格式模板优先：有format_templates时以其为准构建
3. 完整性：格式模板中的每一项都必须出现
4. 每个节点必须有level、title、content、children四个字段
5. 只输出JSON，不要有其他解释文字
6. JSON字段值中双引号用中文引号替代
7. 多包共用评分标准时（scoring_shared=true），只生成一份通用框架，顶层添加 `"applicable_packages": ["1","2",...]`（从packages数组取所有id），框架内容不按包区分
8. **DOCX格式内容自动注入**：如果analysis中包含docx_paragraphs字段，is_free_form=false的节点content由程序注入，你只需确保骨架结构正确
