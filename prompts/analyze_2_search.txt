# 检索任务

对每个非价格类评分因素，执行以下流程：

## Step 1：解析评分因素的description

从description中识别3类信息：
- **子项列举**：如"至少包含A、B、C"、"包括X、Y、Z" → 记录为children
- **章节引用**：如"第五章 二"、"满足采购需求要求"、"详见技术和服务要求" → 记录引用位置
- **评分细则**：得分档次描述（如"方案完整得3分，缺一项扣1分"）→ 记录为scoring_criteria

## Step 2：全文检索

以评分因素名称和子项关键词为线索，**扫描全文所有章节**（不限于某个特定章节），提取所有相关段落的原文。

**检索范围**：技术要求、服务要求、采购需求、投标须知、商务条件、项目概况等所有章节。同一主题在多个章节出现时，必须合并提取。

**检索方式**：
- 用评分因素名称作为主关键词搜索
- 用sub_items中的每个子项作为辅助关键词搜索
- 用description中提到的关键词搜索
- 如果原文中有特殊标记（如★、▲、"不可偏离"等），必须原样保留

## Step 3：章节引用内容提取

当description中引用了具体章节（如"满足第五章 二 要求"、"详见采购需求"等）：
- 定位该章节在全文中的位置
- **完整提取**该章节的所有内容，保留原文编号和层级结构
- 包括所有★标记项和非★项
- 这是最容易遗漏的地方——评分表说"满足XX要求"，就必须把XX的完整内容提取出来

## Step 4：判断展开方式

- `expand_as_children: true`：评分因素有明确子项（description中列举了、或sub_items非空）→ 需展开为子节点
- `expand_as_children: false`：证明材料类（业绩、资质、满意度等）或无明确子项 → 不展开

# 输出格式

对每个非价格类评分因素输出一条记录，严格按以下JSON格式：

```json
[
  {
    "scoring_factor": "评分因素名称",
    "score": 3.0,
    "category": "technical",
    "expand_as_children": true,
    "scoring_criteria": "评分细则原文（得分档次描述，逐字复制）",
    "chapter_reference": "description中引用的章节位置（如无则为空字符串）",
    "referenced_content": "当chapter_reference非空时，该章节的完整原文内容（保留编号、层级及原文中的特殊标记）",
    "children": [
      {
        "title": "子项标题",
        "content": "从全文检索提取的与该子项相关的所有原文内容（完整复制，不概括）"
      }
    ]
  }
]
```

# 字段说明

- `scoring_factor`：评分因素名称，与scoring_factors中的name一致
- `score`：分值
- `category`：technical/commercial
- `expand_as_children`：是否需要展开为子节点
- `scoring_criteria`：评分细则原文，直接从评分表复制
- `chapter_reference`：description中引用的章节位置原文（如"第五章 二 技术和服务要求"、"采购需求第3节"等）。不要硬编码章节号，完全根据description中的实际引用文字填写
- `referenced_content`：引用章节的完整内容。必须去原文定位并完整提取，不能为空（除非chapter_reference本身为空）
- `children[].title`：子项标题，来源优先级：①sub_items原文 ②description中的列举项
- `children[].content`：该子项对应的全文检索结果。不能为空（除非全文确实没有相关内容，此时写"（招标文件未提供具体要求，投标人自行编制）"）

# 注意事项

1. **完整性是第一优先级**：每个子项的content必须包含全文中所有相关内容，遗漏会导致后续步骤无法准确生成框架
2. **不概括、不缩写**：content必须是原文的完整复制，不是你的总结
3. **跨章节合并**：同一主题在多个章节出现时，合并到同一个content中
3a. **多包去重**：当文档有多个采购包且同一要求按包重复出现时（如包1的师资要求、包2的师资要求、包3的师资要求内容基本相同），只提取一份代表性内容。仅当各包要求存在实质差异时（如培训地点、人数不同），用"包1：…/包2：…"格式简要标注差异，不要把相同文字重复多遍
4. **章节引用必须提取**：chapter_reference非空时，referenced_content绝不能为空
5. 价格类评分因素（category为price）不需要处理，直接跳过
6. 只输出JSON数组，不要有其他解释文字
7. JSON字段值中双引号用中文引号替代
8. 完整输出，不得省略或缩减
